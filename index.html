Политика конфиденциальности

Дата вступления в силу: 22 мая 2026 г.

Настоящая Политика конфиденциальности описывает, какие данные могут обрабатываться при использовании мобильной игры Noble Numbers.

1. Общая информация

Мобильная игра Noble Numbers предназначена для развлекательного использования. Приложение может содержать рекламу.

2. Какие данные обрабатываются

Само приложение не запрашивает доступ к контактам, камере, микрофону, геолокации или файлам пользователя.

Для работы рекламы могут обрабатываться технические данные устройства, сведения о взаимодействии с рекламой, IP-адрес, данные о сети, рекламные идентификаторы и иные технические данные, необходимые для показа рекламы, ограничения частоты показов, аналитики и предотвращения мошенничества.

3. Реклама

В приложении используется рекламный SDK MyTarget / VK Ads. Пользователь может видеть рекламные объявления, включая rewarded video — вознаграждаемую рекламу, за просмотр которой может выдаваться игровая награда.

4. Локальные данные

Приложение может сохранять на устройстве пользователя игровые настройки, лучший счёт и игровой прогресс. Эти данные используются только для работы игры.

5. Передача данных третьим лицам

Данные, связанные с рекламой, могут обрабатываться рекламной платформой MyTarget / VK Ads в соответствии с её правилами и политиками.

6. Согласие пользователя

Используя приложение, пользователь подтверждает, что ознакомился с настоящей Политикой конфиденциальности. Если пользователь не согласен с условиями, он должен прекратить использование приложения.

7. Возрастные ограничения

Приложение предназначено для пользователей, соответствующих возрастному рейтингу, указанному в карточке приложения в магазине RuStore.
