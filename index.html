Политика конфиденциальности

Дата вступления в силу: 23 мая 2026 г.

Настоящая Политика конфиденциальности описывает, какие данные могут обрабатываться при использовании мобильной игры Noble Numbers.

1. Общая информация

Noble Numbers — мобильная игра для Android, предназначенная для развлекательного использования. Приложение может содержать рекламу.

Идентификатор приложения: com.al93zv.noblenumbers.

2. Какие данные обрабатываются

Само приложение не запрашивает доступ к контактам, камере, микрофону, геолокации, SMS, журналу звонков или файлам пользователя.

Для работы приложения локально сохраняются игровые настройки, выбранное пользователем решение о показе рекламы, лучший счёт и игровой прогресс. Эти данные хранятся на устройстве пользователя и используются для корректной работы игры.

После согласия пользователя на показ рекламы рекламный провайдер может обрабатывать технические данные, включая сведения об устройстве, IP-адрес, данные о сети и сведения о взаимодействии с рекламой, если это необходимо для показа рекламы, ограничения частоты показов, аналитики и предотвращения мошенничества. Приложение не запрашивает Android-разрешение для доступа к рекламному идентификатору.

3. Реклама

В приложении используется рекламный SDK MyTarget / VK Ads. Пользователь может видеть рекламные объявления, включая rewarded video — вознаграждаемую рекламу, за просмотр которой может выдаваться игровая награда.

Просмотр вознаграждаемой рекламы является добровольным. Пользователь может отказаться от просмотра такой рекламы, но в этом случае соответствующая игровая награда может быть недоступна.

До выбора пользователя рекламный SDK не загружает рекламные объявления. Если пользователь выбирает «Отклонить», приложение не загружает вознаграждаемую рекламу. Решение можно позднее изменить в настройках приложения.

4. Цели обработки данных

Данные могут использоваться для следующих целей:

  • обеспечение работы приложения;
  • сохранение игрового прогресса и настроек;
  • показ рекламы;
  • ограничение частоты показов рекламы;
  • анализ эффективности рекламы;
  • предотвращение мошенничества и злоупотреблений.

5. Передача данных третьим лицам

Только после согласия пользователя данные, необходимые для рекламного показа, могут обрабатываться рекламной платформой MyTarget / VK Ads и её партнёрами в соответствии с их правилами и политиками конфиденциальности.

Разработчик не продаёт персональные данные пользователей третьим лицам.

6. Согласие пользователя

При первом запуске приложение предлагает пользователю принять или отклонить обработку данных для показа рекламы и предоставляет ссылку на настоящую Политику. Отклонение не препятствует использованию игры, но рекламные игровые награды становятся недоступны.

7. Возрастные ограничения

Приложение предназначено для пользователей, соответствующих возрастному рейтингу, указанному в карточке приложения в магазине RuStore.

8. Хранение данных

Локальные игровые данные, такие как настройки, лучший счёт и прогресс, могут храниться на устройстве пользователя до удаления приложения или очистки данных приложения пользователем.

Приложение исключает свои локальные данные из резервного копирования и переноса Android на другое устройство.

9. Изменения политики

Разработчик может периодически обновлять настоящую Политику конфиденциальности. Актуальная версия Политики всегда доступна на этой странице.
