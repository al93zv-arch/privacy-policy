This Privacy Policy explains how the Noble Numbers mobile game for Android handles data.

1. General information

Noble Numbers is a mobile puzzle game for Android.

Application ID: com.al93zv.noblenumbers

2. Data processed by the game

The game does not request access to contacts, camera, microphone, precise location, SMS, call logs, or user files.

Game settings, board size, best scores, and current game progress are stored locally on the device. The developer does not receive this local game data.

3. Advertising and data sharing

The game uses voluntary rewarded advertising from VK Ads / myTarget. An ad is shown only after the user explicitly presses the button to receive an in-game reward. The game does not use banners or automatic ads after gameplay actions.

The advertising SDK may process device and app technical data, the Android advertising ID, ad impressions and interactions, network data, and diagnostic information. This data is shared with VK Ads / myTarget and may be used to serve ads, prevent fraud, limit ad frequency, measure performance, and comply with legal requirements.

By default, the game does not tell the advertising SDK that the user has consented to personalized ads.

4. Android permissions

The game may use vibration for gameplay feedback. This permission does not provide access to personal data.

Internet access, network state, and the Android advertising identifier may be used to deliver rewarded ads.

5. Retention and deletion

Local game data remains on the device until the user clears the app data or uninstalls the game.

Advertising platform retention and deletion practices are governed by the platform's policies. Users can restrict advertising ID use in Android privacy settings.

6. Children

The game is intended for a general audience and is not specifically directed at children.

7. Policy changes

This Privacy Policy may be updated when the game's features or store requirements change.
