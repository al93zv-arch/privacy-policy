This Privacy Policy explains how the Noble Numbers: Королевская 2048 mobile game for Android handles data.

1. General information

Noble Numbers: Королевская 2048 is a mobile puzzle game for Android.

Application ID: com.al93zv.noblenumbers.royal2048

2. Data processed by the game

The game does not request access to contacts, camera, microphone, precise location, SMS, call logs, or user files.

Game settings, board size, best scores, and current game progress are stored locally on the device. The developer does not receive this local game data.

3. Advertising and data sharing

Version 1.0 contains a prepared Yandex Advertising Network integration through the Yandex Mobile Ads SDK, but no ad units are configured in this version. Banner and full-screen ads are not shown to users.

Advertising formats may be enabled only in a separate future application update. The store description and this Privacy Policy will be updated before such a release.

Yandex advertising services may process the advertising identifier and other device identifiers when the corresponding Android permission is available. This information is transferred over a secure connection and may be used for advertising or marketing. Automatic SDK initialization is disabled; the advertising SDK can be accessed only after the user makes a choice on the privacy screen.

The user can choose whether to allow advertising data personalization. The choice is stored on the device and can be changed from the Privacy screen in the game settings.

For more information about Yandex data processing, see the Yandex Privacy Policy.

4. Android permissions

The game may use vibration for gameplay feedback. This permission does not provide access to personal data.

The prepared advertising SDK may use internet access, network state, and the Android advertising identifier. Advertising is disabled in version 1.0.

5. Retention and deletion

Local game data remains on the device until the user clears the app data or uninstalls the game.

Advertising platform retention and deletion practices are governed by the platform's policies. Users can restrict advertising ID use in Android privacy settings.

Requests to delete data associated with advertising services can be sent to the developer at alex.zv40@yandex.ru.

6. Children

The game is intended for a general audience and is not specifically directed at children.

7. Policy changes

This Privacy Policy may be updated when the game's features or store requirements change.
