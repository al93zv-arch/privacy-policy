This Privacy Policy explains how the Noble Numbers mobile game for Android handles data.

1. General information

Noble Numbers is a mobile puzzle game for Android.

Application ID: com.al93zv.noblenumbers

2. Data processed by the game

The game does not request access to contacts, camera, microphone, precise location, SMS, call logs, or user files.

Game settings, board size, best scores, and current game progress are stored locally on the device. The developer does not receive this local game data.

3. Advertising and data sharing

The game uses the Yandex Advertising Network through the Yandex Mobile Ads SDK. A small banner is displayed only during active gameplay and is hidden in the main menu, settings, and selection screens.

If no valid moves remain, the player may choose to watch a full-screen rewarded ad to shuffle the tiles. This ad starts only after an explicit button press and is not required to launch the game.

Yandex advertising services, including AppMetrica components, may process device and app technical data, the Android advertising ID, IP address and network information, install information, ad impressions and interactions, and diagnostic data. This information may be used to serve and measure ads, provide analytics, limit ad frequency, prevent fraud, and comply with legal obligations.

On first launch, the user chooses whether to allow ad personalization. The choice is stored on the device and can be changed from the Privacy screen in the game settings.

For more information about Yandex data processing, see the Yandex Privacy Policy.

4. Android permissions

The game may use vibration for gameplay feedback. This permission does not provide access to personal data.

Internet access, network state, and the Android advertising identifier may be used to deliver banner and rewarded ads.

5. Retention and deletion

Local game data remains on the device until the user clears the app data or uninstalls the game.

Advertising platform retention and deletion practices are governed by the platform's policies. Users can restrict advertising ID use in Android privacy settings.

6. Children

The game is intended for a general audience and is not specifically directed at children.

7. Policy changes

This Privacy Policy may be updated when the game's features or store requirements change.
